# Free Study Std.Hub

A starter educational platform with:
- Public student website
- Subjects and questions
- Search
- Admin login
- Admin CRUD for subjects and questions
- SQLite database
- Responsive design

## Run
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run: `npm install`
4. Run: `npm start`
5. Open: http://localhost:3000
6. Admin: http://localhost:3000/admin.html

Default admin credentials (change them before real deployment):
- Username: admin
- Password: bu++er3ry

The database is created automatically in `data/studyhub.db`.
